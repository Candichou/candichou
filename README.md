## 🚀 Projet à suivre — Abi

**Abi** est une application web imaginée autour d'un enjeu : faciliter l'accès à des professionnel·les de santé auprès desquels les patient·es peuvent se sentir écouté·es et en confiance, avec une attention particulière portée aux personnes confrontées à des discriminations ou à des besoins spécifiques.

Le projet me permet de travailler toute la chaîne de réflexion :

**Recherche utilisateur → définition du besoin → UX → développement → données → amélioration**

J'ai notamment réalisé un premier questionnaire auprès de patient·es afin de confronter mon idée aux usages réels.

Le projet est encore en développement : les données actuellement utilisées sont fictives et l'application n'est pas destinée à un usage médical réel à ce stade.
